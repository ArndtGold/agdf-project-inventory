# Inventory Report Structure

The validated report contains:

1. decision context
2. scope and exclusions
3. evidence coverage and limitations
4. observations and interpretations
5. unknowns and conflicts
6. recommendations
7. review state and report limitations

Every material statement retains its stable ID, exact rendered text, derived epistemic state and
evidence references. The report index records source digests, included IDs, statement text digests,
section presence and the final report digest.

Do not introduce report statements that are absent from the validated registers.
