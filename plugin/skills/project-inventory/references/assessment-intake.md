# Assessment Intake Structure

Capture only user- or source-provided values for:

- decision context and intended decision owner
- audience and review owner
- in-scope topics and explicit exclusions
- authorized repository roots and external-system locators
- time boundary and permitted unknowns
- confidentiality classification

Do not preselect scope, risk, sufficiency, readiness or a conclusion. Missing required information
remains visible and prevents report-ready state. A question may be emitted only when the approved
scope, the active schema or a mapped validation result requires it; the rendered question is copied
verbatim and never invented from model judgement.
